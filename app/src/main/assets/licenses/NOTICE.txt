Corresponding source:
  The CI run producing this APK also publishes the
  emu-qemu-9.2.0-corresponding-source artifact and its .sha256 sidecar.
  It contains QEMU 9.2.0 source, pinned dependency source trees,
  repository patches, build scripts, and source/license manifests.

QEMU executables dynamically link only Android public system libraries:
libc.so, libm.so, libdl.so, and libz.so. These operating-system libraries
are not copied into the APK as private shared-library dependencies.

Build tools and host-only dependencies are intentionally excluded from this
APK inventory. Android platform APIs are provided by the operating system and
are not bundled as application libraries.
